How we harmonize, and how well it works

Clean. We keep vegetation fires only (FIRMS type 0), drop low-confidence detections (MODIS confidence < 30, VIIRS “low”), and remove duplicates.

Grid. Detections are counted as fire cell-days: the number of 0.05° grid cells (~5 km) with at least one detection on a given day, each counted once however many detections fall in it. This is the project’s own metric, not a FIRMS product, chosen so that pixel size matters less: it blunts the resolution gap between MODIS (1 km) and VIIRS (375 m). It measures where and for how long fire was detected, not area burned.

Learn the conversion. On overlap years (2012–2019, before the MODIS orbits drifted) we fit, for each calendar month, how many VIIRS cell-days each MODIS cell-day is worth, separately for weak and strong (high-FRP) MODIS detections. VIIRS’ finer pixels add far more detections around small, weak fires than around big intense ones, so one flat ratio would overstate big-wildfire years. A simple monthly ratio is kept as a baseline for comparison.

Alternative: quantile mapping. For each month we also match the distribution of per-cell MODIS fire days to the VIIRS distribution (a cell with k MODIS fire days maps to the VIIRS count at the same percentile, scaled for the extra cells VIIRS lights up). All methods are scored the same way below; the one marked “in use” is set in pipeline/config.py.

Convert. MODIS-only years (before 2012) are converted with that monthly fit, so the whole record reads in VIIRS-equivalent units. Months before July 2002 had only Terra (Aqua had not started), so they are first scaled up to Terra+Aqua. Converted months carry a 10–90% uncertainty band in the calendar tooltips.

After Suomi NPP. The VIIRS record here is the one on Suomi NPP, which stopped delivering new observations on 2 November 2026. Later months (and the live current month, when the server has a FIRMS key) come from the VIIRS on NOAA-20, scaled to Suomi NPP units with a factor fitted while both satellites flew.
